自主导航：使用Nav2，EKF的三维模式，导致了小车有了z轴。终端返回了空的路径。根因：`ekf.yaml` 的 `two_d_mode: false`，差速车被当作三维物体估计- 解决：`two_d_mode: true`，切换为二维模式，将Z轴锁死为 0
